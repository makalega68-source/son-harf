# Store frame acceptance checklist

- Six new frame IDs are client-supported.
- All six production frame resources use a 512×512 vector viewport.
- Son Coin purchases call the server-authoritative `purchase_shop_item` RPC.
- Successful purchase immediately equips through `equip_shop_item`.
- Owned frames remain selectable through Profile → Collection.
- Decorative wings/blossoms receive extra avatar clearance.
- PRO Golden is not sold and remains unchanged.
