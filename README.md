# Son Harf

Android için iki kişilik gerçek zamanlı Türkçe kelime düellosu.

## MVP
- Kotlin + Jetpack Compose
- İki kişilik oda / davet kodu
- Son harfle kelime zinciri
- Süreli turlar
- Sohbet ve rövanş
- Profil ve maç geçmişi
- VIP abonelik ve uygulama içi ürün altyapısı
- Supabase Auth, Postgres, Realtime ve Edge Functions
- Google Play Billing

## Güvenlik
Oyun sonucu, ekonomi ve satın alma yetkilendirmesi istemciye güvenmeden sunucu tarafında doğrulanacaktır.
