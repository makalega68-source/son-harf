# Home Lobby

Integrated lobby hierarchy:

1. Profile / league / rating / streak / Son Coin
2. Dominant OYNA action
3. Son Harf and Bil Bakalim game choices
4. Nearest league target
5. Daily mission
6. Active tournament
7. Rematch / last rival
8. Five-item bottom navigation: Home, League, Friends, Style, Profile

Mascot features are explicitly disabled. Ads/VIP are not promoted on the primary lobby. Competitive rewards remain non-pay-to-win.
